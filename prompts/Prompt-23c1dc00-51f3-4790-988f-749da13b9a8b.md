## Prompt

> Lägg till stöd för en rabattkod som ger 10 % rabatt på hela kvittot. Rabatten ska dras innan momsen räknas. Skriv tester för det nya.

*(English: Add support for a discount code that gives 10 % off the whole receipt. The discount must be applied before VAT is calculated. Write tests for the new functionality.)*

> committa ändringarna och pusha till github

*(English: Commit the changes and push to GitHub.)*

## Changes

### `raknare.py`
- Added a `DISCOUNT_CODES` dictionary mapping code → discount rate (`"RABATT10": 0.10`).
- Added an optional parameter `discount_code=None` to `berakna_total`.
- The discount is applied to each item's price **excluding VAT**, and VAT is calculated on the discounted price.
- An unknown discount code raises `ValueError`.
- Extended the `__main__` example with a discounted total.

### `readme.md`
- Filled in the Claude Code row of the results table at commit time.

### `test_knappraknare.py`
- New test class `TestDiscountCode` with five tests:
  - 10 % discount on a receipt with a single VAT rate
  - Discount applied before VAT on a receipt with mixed VAT rates
  - `None` as code gives the full price
  - Unknown code raises `ValueError`
  - Discount on an empty receipt returns `0`

## Assumptions
- The discount code is named **`RABATT10`** (no name was specified).
- Codes are **case-sensitive** (`rabatt10` is not valid).
- An **unknown code raises `ValueError`** rather than being silently ignored.
- The existing function name `berakna_total` was kept to avoid breaking existing callers; only new identifiers are in English.
- Only one discount code can be used per receipt.
- No new dependencies were added.
- Compiled `__pycache__` files were left out of the commit.
